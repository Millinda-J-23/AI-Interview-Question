# 🤖 AI Interview Question Generator

An AI-powered web application that helps students and job seekers prepare for interviews by generating personalized interview questions based on the selected company, job role, experience level, difficulty, and skills.

## 🚀 Live Demo
https://ai-interview-question.onrender.com/

## 💻 GitHub Repository
https://github.com/Millinda-J-23/AI-Interview-Question

## ✨ Features

- AI-powered interview question generation
- Company and role-specific interview questions
- User Registration & Login
- Interview History
- Download interview questions as PDF
- Responsive user interface

## ⚙️ Installation

```bash
git clone https://github.com/Millinda-J-23/AI-Interview-Question-Generator.git
cd AI-Interview-Question-Generator

python -m venv venv

# Windows
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```
